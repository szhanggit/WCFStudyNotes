Can we use .NET Remoting to build a web service?
yes.

If the client is not built using .NET platform, will they be able to consumer a .NET Remoting web service?
They can, but we need to be very careful in choosing the data types that we use in the service, and client-activated
objects and events should be avoided. Keep in mind .NET Remoting is not meant for implementing interoperable services.
If your goal is to build interoperable services, it is better to use ASP.NET Web Services.

Compared with WCF, both .NET remoting and ASP.NET Web Services are legacy technologies.
